1. 引言

标准模型（Standard Model, SM）是粒子物理学迄今为止最为成功的理论框架，但其内部仍遗留着一系列深刻的未解之谜。其中，强 CP 问题与夸克质量层级问题被视为通往更底层物理理论的两个关键瓶颈。

$$\mathcal{L}_{\text{CP}} = \frac{\bar{\theta}_{\text{QCD}}}{32\pi^2} G_{\mu\nu}^a \tilde{G}^{a\mu\nu}$$

3. 强 CP 问题的拓扑消除

3.1 $\bar{\theta}_{\text{QCD}} \equiv 0$ 的第一性原理证明

标准模型量子色动力学（QCD）中包含 CP 破坏的拉氏量有效项表示为：

$$\mathcal{L}_{\bar{\theta}} = \frac{\bar{\theta}_{\text{QCD}}}{32\pi^2} G_{\mu\nu}^a \tilde{G}^{a\mu\nu} \tag{4}$$

其中 $\bar{\theta}{\text{QCD}} = \theta{\text{QCD}} + \arg\det(M_q)$ 为规范真空角与夸克质量矩阵手征相角叠加后的总物理相角。中子电偶极矩（nEDM）的实验测量值要求 $\vert{}\bar{\theta}_{\text{QCD}}\vert{} &lt; 10^{-10}$。

定理 3.1（真空拓扑缠绕数归零）：在 3T1S 流形下，非阿贝尔 gauge 场构型在四维时空流形上的 Pontryagin 拓扑示性类积分：

$$Q = \frac{1}{32\pi^2} \int_{\mathcal{M}} d^4x , G_{\mu\nu}^a \tilde{G}^{a\mu\nu} \in \mathbb{Z} \tag{5}$$

受公理三迹守恒条件 $\delta\text{Tr}(\hat{g}) \equiv 0$ 的全局几何约束。由于 3T 时序相空间具有正交封闭循环周期，无穷远边界上的规范场映射不存在非平凡的自由缠绕。在基态真空演化下，拓扑荷 $Q$ 被强制裁剪至零拓扑扇区：

$$Q \equiv 0 \implies \theta_{\text{QCD}} = 0 \tag{6}$$

定理 3.2（手征相位相销）：夸克质量矩阵 $M_q$ 由 3T 相空间向 1S 空间的迹守恒投影生成。根据公式 (1)，质量矩阵在全局 $\text{SU}(3)_c \otimes \text{SU}(2)_L \otimes \text{U}(1)_Y$ 变换下保持 Hermite 对称性，其行列式对角化后的虚相在迹守恒约束下严格消隐：

$$\arg\det(M_q) \equiv 0 \tag{7}$$

由定理 3.1 与定理 3.2 可得：

$$\bar{\theta}_{\text{QCD}}^{\text{(11T)}} = \theta_{\text{QCD}} + \arg\det(M_q) \equiv 0 \tag{8}$$

推论 3.1：强 CP 问题在 11T-矩阵框架下是一个天然归零的拓扑约束定理，不存在微调张力，因而无需假定 Peccei-Quinn U(1) 手征对称性及轴子粒子（Axion）的存在。
