二、从探针方程逼出 c 的表达式

把三个量的量纲摊开：$G$ [L³/(M·T²)]、$E_V$ [M/(L·T²)]、$c$ [L/T]。它们必然满足一个只含无量纲拓扑常数的关系。

而局域探针方程 $E_V = \pi a_0^2 / G$ 直接给出：

$$\sqrt{G\cdot E_V} = \frac{a_0}{\sqrt{\pi}}$$

$$c = \mathcal{K} \cdot a_0 \cdot \mathcal{T}$$

其中 $\mathcal{K}$ 为无量纲拓扑常数，$\mathcal{T}$ 为该尺度对应的特征时序。

在微观尺度（EPD-04），加速度为弥散加速度 $a = c^2/\lambda_{\rm topo}$，时序尺度为根域步长 $\tau_0$，结果：

2.2 宇宙学尺度：$\mathcal{K}_{\rm cosmic} = 2\pi$

在宇宙学尺度，加速度为临界加速度 $a_0$，时序尺度为哈勃时间 $H_0^{-1}$。本文将证明（见 2.3 节）：

$$c = 2\pi \cdot a_0 \cdot H_0^{-1}$$

为清晰起见，下文将区分裸值与观测值：

  • $a_{0({\rm bare})} = cH_0$：理想连续流形下、尚未计入拓扑稀释的临界加速度；
  • $a_{0({\rm obs})} = cH_0/(2\pi)$：计入 $2\pi$ 闭合缠绕稀释后的宏观可观测临界加速度。

八、结论

《局域真空探针》一文（$E_V=\pi a_0^2/G$）不是孤立成果，而是整个拼图的中心枢纽：它通过标定介质状态，把 G（刚度）与 c（波速）锁进同一个方程 $c = \mathcal{K} a_0 \mathcal{T}$。G 刚性的研究由此成为 c 的唯一突破口——测 G 的地方，就是测 c 的地方。

更意外的是：本文从全息热力学平衡独立推导了 $a_{0({\rm bare})} = cH_0$，再经 3T→1S 闭合回路的 $2\pi$ 相位积分得到 $a_{0({\rm obs})} = cH_0/(2\pi)$，将 MOND 经验公式降格为 11T-Matrix 的推论，彻底消除了循环论证。由此得到 $c = 2\pi a_0 H_0^{-1}$，数值与真实光速偏差约 7%–11%（落在哈勃张力范围内）。由 $c$ 的绝对刚性进一步推出预言 P4：$a_0(z) \propto H_0(z)$，构成可证伪的定量约束。宇宙学尺度与微观尺度在 $c = \mathcal{K} a \mathcal{T}$ 下实现统一，EPD-03、EPD-04、EPD-05 由此构成完整闭环。

核心一句话： G 与 c 同源于根域介质；介质状态由 $a_0$ 标定；故 G 刚性 ⇔ c 刚性，G 滑移处 c 同步滑移。

A.3 动力学根源：相对论弦自稳定

普通介质做不到： 普通介质的波速 $v = \sqrt{\text{弹性模量}/\rho}$。密度一变，波速必变。水的声速变 5 倍。量子海若照此规律，40 个数量级的能量变化早已使 $c$ 面目全非。

相对论弦的天然免疫： Nambu-Goto 弦有一条定义性关系：

$$T = \mu c^2$$

其中 $T$ 为弦张力，$\mu$ 为线密度，$c$ 为根域光速。由此弦上的波速：

$$v = \sqrt{\frac{T}{\mu}} = \sqrt{\frac{\mu c^2}{\mu}} = c$$

$\mu$ 消掉了。 无论线密度如何变化，张力与密度的比值自动恒定，波速严格等于 $c$。

严谨性说明： $T = \mu c^2$ 是 Nambu-Goto 弦的定义性设定（作用量 $S = -T \int d^2\sigma$ 中 $T = \mu c^2$），并非从第一性原理推导的定理。本文将其作为 11T-Matrix 的体系内假设引入；从 $M_3$（时序饱和度）与 $M_4$（自旋拓扑）严格推出此关系仍是待完成项（见 A.7）。

能量密度变化时微观上发生了什么：

  1. 层次B变化：联络间距拉大，$n_{\rm link}$ 急剧下降，单个联络的能量承载减少；
  2. 层次A不变：单根弦的 $\lambda_{\rm topo}$、$\tau_0$ 仍由拓扑锁定，$T = \mu c^2$ 关系在每根弦上依然成立；
  3. 结果：每根弦上的波速仍然是 $c$。整片量子海的宏观响应（$G$、$c$）不变。
