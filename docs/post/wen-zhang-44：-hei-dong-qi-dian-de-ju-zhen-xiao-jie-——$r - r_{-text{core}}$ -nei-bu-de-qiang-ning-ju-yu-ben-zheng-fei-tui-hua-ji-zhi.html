2 内部空间的强凝聚有效方程与解析解

$\frac{1}{r^2}\frac{d}{dr}\left(r^2 \frac{d\rho_{\text{inner}}}{dr}\right) - \frac{1}{r_{\text{root}}^2}(\rho_{\text{inner}} - \rho_\infty) = -\lambda_{\text{core}} \rho_{\text{Higgs_cond}}$

  • ρ_Higgs_cond：希格斯高维凝聚能标，复用电弱扇区已闭合的真空期望值v_EW。

2.2 内部通用解的代数推导

为求解此非齐次微分方程，定义松弛偏离变量：

$\tilde{\rho}(r) = \rho_{\text{inner}}(r) - \rho_\infty - \lambda_{\text{core}} r_{\text{root}}^2 \rho_{\text{Higgs_cond}}$

代入原方程后，转化为标准的单振子齐次式：

$\frac{d^2(r\tilde{\rho})}{dr^2} - \frac{1}{r_{\text{root}}^2}(r\tilde{\rho}) = 0$

其通解由双曲正弦与双曲余弦函数线性组合构成：

$r\tilde{\rho}(r) = C \sinh\left(\frac{r}{r_{\text{root}}}\right) + D \cosh\left(\frac{r}{r_{\text{root}}}\right)$

两边同除以r，得到内部空间能量密度的通用解析式：

$\rho_{\text{inner}}(r) = \rho_\infty + \lambda_{\text{core}} r_{\text{root}}^2 \rho_{\text{Higgs_cond}} + C \frac{\sinh(r/r_{\text{root}})}{r} + D \frac{\cosh(r/r_{\text{root}})}{r}$

3 零点拦截：奇点的数学消解与有限最大密度

3.1 零点边界条件的刚性约束

在通用解析解中，第四项包含分式cosh(r/r_root)/r。当r→0时，分子cosh(0)=1而分母r→0，该项将导致中心能量密度发生1/r形式的几何级数发散。

根据纲领层名额排他公理，11个时序矩阵位点具备本征物理饱和度极限，其代数模态绝对不允许发生无限发散（无退化物理量）。为保证中心本征值的拓扑稳定性，必须实行刚性拦截，强制约束积分常数：

$D \equiv 0$

此时解中仅保留第三项。当r→0时，利用泰勒级数展开评估该项的极限行为：

$\lim_{r \to 0} \frac{\sinh(r/r_{\text{root}})}{r} = \lim_{r \to 0} \frac{\frac{r}{r_{\text{root}}} + \frac{1}{6}\left(\frac{r}{r_{\text{root}}}\right)^3 + \dots}{r} = \frac{1}{r_{\text{root}}}$

底层机制对应：文章46的离散图论框架进一步证明，该拦截并非人为设定，而是拓扑漏斗顶点出度为零的代数必然，连续方程的发散项在离散本体中天然不存在。

3.2 中心有限最大值ρ_max的诞生

将约束条件D=0及零点极限值反代回方程，得到黑洞绝对中心的核心物理结果——核心最大有限能量密度ρ_max：

$\rho_{\text{max}} = \rho_{\text{inner}}(0) = \rho_\infty + \lambda_{\text{core}} r_{\text{root}}^2 \rho_{\text{Higgs_cond}} + \frac{C}{r_{\text{root}}}$

4 内外解的无缝衔接（零新增自由参数）

$\rho_{\text{outer}}(r) = \rho_\infty + (\rho_{\text{core}} - \rho_\infty)\frac{r_{\text{core}}}{r} e^{-(r - r_{\text{core}})/r_{\text{root}}}$

$\rho_{\text{inner}}(r_{\text{core}}) = \rho_{\text{outer}}(r_{\text{core}}) = \rho_{\text{core}}$

$\rho_\infty + \lambda_{\text{core}} r_{\text{root}}^2 \rho_{\text{Higgs_cond}} + C \frac{\sinh(r_{\text{core}}/r_{\text{root}})}{r_{\text{core}}} = \rho_{\text{core}}$

$C = \frac{r_{\text{core}}}{\sinh(r_{\text{core}}/r_{\text{root}})} \left[ \rho_{\text{core}} - \rho_\infty - \lambda_{\text{core}} r_{\text{root}}^2 \rho_{\text{Higgs_cond}} \right]$
