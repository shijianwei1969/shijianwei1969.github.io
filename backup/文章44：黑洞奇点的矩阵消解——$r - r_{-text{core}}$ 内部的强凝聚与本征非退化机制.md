## 2 内部空间的稳态扩散方程与边界解析

### 2.1 内部动力学方程

在星系核心或超大质量黑洞内部（$r < r_{\text{core}}$），源项 $S_{\text{core}}$ 全面激活。根域能量在局域发生强烈的希格斯高维凝聚（$\rho_{\text{Higgs\_cond}}$）。内部平移扩散方程写为：

$\frac{1}{r^2}\frac{d}{dr}\left(r^2 \frac{d\rho_{\text{root}}}{dr}\right) - \frac{1}{r_{\text{root}}^2}(\rho_{\text{root}} - \rho_\infty) = -\lambda_{\text{core}} \rho_{\text{Higgs\_cond}}$

其中 $\rho_{\text{Higgs\_cond}}$ 为局域希格斯凝聚密度，在核心内部视为均匀常数。

### 2.2 内部解的数学推导

为了求解该非齐次微分方程，我们定义松弛偏离变量：

$\tilde{\rho}(r) = \rho_{\text{root}}(r) - \rho_\infty - \lambda_{\text{core}} r_{\text{root}}^2 \rho_{\text{Higgs\_cond}}$

代入原方程后，方程转化为标准的齐次单振子方程：

$\frac{d^2(r\tilde{\rho})}{dr^2} - \frac{1}{r_{\text{root}}^2}(r\tilde{\rho}) = 0$

其通解形式为：

$r\tilde{\rho}(r) = C \sinh\left(\frac{r}{r_{\text{root}}}\right) + D \cosh\left(\frac{r}{r_{\text{root}}}\right)$

由此得到内部空间的根域能量密度分布通用表达式：

$\rho_{\text{root}}(r) = \rho_\infty + \lambda_{\text{core}} r_{\text{root}}^2 \rho_{\text{Higgs\_cond}} + C \frac{\sinh(r/r_{\text{root}})}{r} + D \frac{\cosh(r/r_{\text{root}})}{r}$

## 3 核心拦截：零点的有限性证明（奇点消解）

### 3.1 零点边界条件（$r \to 0$）

现在我们来审视传统物理学崩溃的绝对核心点：$r = 0$。

在通用解析解中，第四项包含 $\frac{\cosh(r/r_{\text{root}})}{r}$。当 $r \to 0$ 时，$\cosh(0) = 1$，而分母 $r \to 0$。这意味着如果 $D \neq 0$，该项将导致中心能量密度直接发生 $1/r$ 的发散。

$D \equiv 0$

此时，第三项在 $r \to 0$ 时的行为通过泰勒级数展开为：

$\lim_{r \to 0} \frac{\sinh(r/r_{\text{root}})}{r} = \lim_{r \to 0} \frac{\frac{r}{r_{\text{root}}} + \frac{1}{6}\left(\frac{r}{r_{\text{root}}}\right)^3 + \dots}{r} = \frac{1}{r_{\text{root}}}$
