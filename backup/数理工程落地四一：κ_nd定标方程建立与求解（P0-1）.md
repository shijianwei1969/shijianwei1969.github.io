## 文章10（二次修订版）：κ_nd定标方程建立与求解（P0-1）

### 第1节：任务定位与方法选择

#### 1.1 P0-1的任务

P0-1是P0（κ_nd内部几何定标）的核心执行阶段。基于P0-0（文章9）的输出，本文的任务是：

1. 建立κ_nd的定标方程
2. 代入候选函数形式，求解耦合常数κ₀
3. 判别κ_nd的实际结构类型
4. 输出κ_nd的定标结果

#### 1.2 方法选择与执行逻辑

按文章5g §4和文章9 §2.4的设定，定标方案的执行顺序为：

**方案B（M₁不变量约束）→ 方案A（三角函数关系）→ 方案C（自然性原则）**

经本文执行后确认，各方案的实际角色为：

按文章9 §2.4.3的列表，候选形式共4种。经分析，方案B的不等式约束对候选1、2、3的效果相同（均只能给出宽松上限），因此跳过候选2和候选3的重复检验，直接进入方案A。候选4（三个独立参数）在方案A的框架下另行处理。

### 第2节：方案B——M₁不变量约束方程

#### 2.1 M₁矩阵的完整形式

引入非对角耦合后，M₁的完整形式为：

$$M_1 = \begin{pmatrix} S_1 & \kappa_{12} & \kappa_{13} \\ \kappa_{12} & S_2 & \kappa_{23} \\ \kappa_{13} & \kappa_{23} & S_3 \end{pmatrix}$$

其中S_i为已知（文章2）：S₁ ≈ 0.7237, S₂ ≈ 0.1508, S₃ ≈ 0.1255，满足∑S_i = 1。

#### 2.2 M₁的不变量

3×3实对称矩阵M₁有三个基本不变量：

**迹（Trace）**：Tr(M₁) = S₁ + S₂ + S₃ = 1

**二阶矩（所有2×2主子式之和）**：

Tr(adj(M₁)) = (S₂S₃ − κ₂₃²) + (S₁S₃ − κ₁₃²) + (S₁S₂ − κ₁₂²)

**行列式（Determinant）**：

det(M₁) = S₁S₂S₃ + 2κ₁₂κ₂₃κ₁₃ − S₁κ₂₃² − S₂κ₁₃² − S₃κ₁₂²

#### 2.3 候选1（双线性耦合）的代入

候选1的形式为：κ_ij = κ₀ · S_i S_j

代入行列式：

det(M₁) = S₁S₂S₃ + 2κ₀³S₁²S₂²S₃² − κ₀²(S₁S₂²S₃² + S₂S₁²S₃² + S₃S₁²S₂²)

代入S_i数值：

- S₁S₂S₃ ≈ 0.0137
- S₁²S₂²S₃² ≈ 1.88 × 10⁻⁴
- S₁S₂²S₃² ≈ 2.60 × 10⁻⁴
- S₂S₁²S₃² ≈ 1.24 × 10⁻³
- S₃S₁²S₂² ≈ 1.49 × 10⁻³

因此：

det(M₁) ≈ 0.0137 + 3.76 × 10⁻⁴ κ₀³ − 2.99 × 10⁻³ κ₀²

#### 2.4 不等式约束：正定性

M₁必须保持正定（所有特征值 > 0）。正定性的充要条件是所有顺序主子式 > 0。

一阶主子式：S₁ > 0, S₂ > 0, S₃ > 0 ✅

二阶主子式给出最紧约束：

S₁S₂ − κ₁₂² > 0

代入候选1：0.7237 × 0.1508 − (κ₀ × 0.7237 × 0.1508)² > 0

0.1091(1 − 0.1091κ₀²) > 0

κ₀ < 1/√0.1091 ≈ 3.03

#### 2.5 等式约束来源分析

方案B目前仅提供了不等式约束（κ₀ < 3.03），无法独立解出κ₀的精确值。原因在于：方案B需要M₁的某个不变量存在已知的目标值，才能建立等式约束。但目前来自根域层的已知量中，尚无这样的目标值。

可能的等式约束来源分析如下：

| 来源 | 是否提供等式约束 | 说明 |
|------|-----------------|------|
| 文章1（α⁻¹推导） | ❌ | α⁻¹是根域圈数读数，与M₁的行列式无直接等式关系 |
| 文章2（Sᵢ推导） | ❌ | Sᵢ的估算来自几何自洽性，未涉及M₁的行列式或二阶矩 |
| 公理体系 | ❌ | 四大公理不直接给出M₁不变量的数值 |
| **方案A（三角函数关系）** | ✅ | 可能提供κ_ij = κ₀·h(θ_i,θ_j)的等式关系 |

**结论**：方案B作为“筛选器”提供了κ₀的上限（κ₀ < 3.03），但精确求解需要方案A的等式约束。

### 第3节：方案B的延伸——特征值微扰分析

#### 3.1 从行列式到特征值

第2节利用行列式约束得到了κ₀ < 3.03。本节利用更精细的工具——特征值微扰展开——来获得更紧的上限。这仍然是方案B框架内的深化，而非方案A。

#### 3.2 特征值微扰展开

M₁可写为M₁ = M₁⁽⁰⁾ + κ₀M₁⁽¹⁾，其中M₁⁽⁰⁾ = diag(S₁,S₂,S₃)，M₁⁽¹⁾的非对角元为S_iS_j，对角元为0。

一阶微扰修正为0（因为M₁⁽¹⁾的对角元为0）。二阶微扰修正为：

δ_i⁽²⁾ = ∑_{j≠i} |(M₁⁽¹⁾)_ij|² / (S_i − S_j) · κ₀²

代入数值：

(M₁⁽¹⁾)₁₂ = S₁S₂ ≈ 0.1091
(M₁⁽¹⁾)₁₃ = S₁S₃ ≈ 0.0908
(M₁⁽¹⁾)₂₃ = S₂S₃ ≈ 0.01894

δ₁⁽²⁾ = κ₀²(0.1091²/0.5729 + 0.0908²/0.5982) = 0.03455κ₀²

δ₂⁽²⁾ = κ₀²(0.1091²/(−0.5729) + 0.01894²/0.0253) = −0.00659κ₀²

δ₃⁽²⁾ = κ₀²(0.0908²/(−0.5982) + 0.01894²/(−0.0253)) = −0.02796κ₀²

验证∑δ_i = (0.03455 − 0.00659 − 0.02796)κ₀² = 0 ✅

#### 3.3 特征值正定性约束

特征值为：

λ₁ ≈ 0.7237 + 0.03455κ₀²
λ₂ ≈ 0.1508 − 0.00659κ₀²
λ₃ ≈ 0.1255 − 0.02796κ₀²

正定性要求所有λ_i > 0。最紧的约束来自λ₃：

0.1255 − 0.02796κ₀² > 0

κ₀² < 0.1255/0.02796 ≈ 4.49

κ₀ < 2.12

#### 3.4 方案B的最终输出

| 约束来源 | 约束类型 | κ₀上限 |
|---------|---------|--------|
| 行列式正定性（第2节） | 不等式 | 3.03 |
| 特征值正定性（第3节） | 不等式 | 2.12 |

特征值微扰分析给出了更紧的上限（κ₀ < 2.12），但仍是不等式约束。方案B的全部潜力已用尽。

### 第4节：方案A的真正执行——三角函数等式约束

#### 4.1 方案A的任务定义

方案A的核心任务是：建立κ_ij与通道夹角θ_i之间的三角函数等式关系：

κ_ij = κ₀ · h(θ_i, θ_j)

其中h是某个三角函数组合，h(x,y) = h(y,x)（对称性）。一旦h的形式确定，代入已知的θ_i数值，即可固定κ₁₂:κ₂₃:κ₃₁的比例关系。再结合中介层反馈或α⁻¹的精确值，就能解出κ₀。

#### 4.2 三角函数候选形式

以下列出三种候选h函数：

**候选h1：正弦乘积**

h₁(θ_i, θ_j) = sinθ_i sinθ_j

物理直觉：通道间的干涉强度正比于各自投影振幅的正弦值。

**候选h2：角度差正弦**

h₂(θ_i, θ_j) = sin|θ_i − θ_j|

物理直觉：干涉强度正比于通道间夹角差的正弦。

**候选h3：余弦组合**

h₃(θ_i, θ_j) = cosθ_i cosθ_j − cos(θ_i+θ_j)

物理直觉：球面三角关系中的干涉项。

#### 4.3 比例关系计算

代入θ_i数值：θ₁ ≈ 1.2870, θ₂ ≈ 0.2680, θ₃ ≈ 0.2230。

**候选h1（正弦乘积）**：

sinθ₁ ≈ sin(1.2870) ≈ 0.9600
sinθ₂ ≈ sin(0.2680) ≈ 0.2650
sinθ₃ ≈ sin(0.2230) ≈ 0.2210

κ₁₂ : κ₂₃ : κ₃₁ = sinθ₁sinθ₂ : sinθ₂sinθ₃ : sinθ₃sinθ₁

= (0.9600×0.2650) : (0.2650×0.2210) : (0.2210×0.9600)

= 0.2544 : 0.05857 : 0.2122

归一化（和=0.5252）：

κ₁₂ : κ₂₃ : κ₃₁ ≈ 0.484 : 0.112 : 0.404

**候选h2（角度差正弦）**：

|θ₁−θ₂| = 1.0190, sin(1.0190) ≈ 0.8510
|θ₂−θ₃| = 0.0450, sin(0.0450) ≈ 0.04498
|θ₃−θ₁| = 1.0640, sin(1.0640) ≈ 0.8720

κ₁₂ : κ₂₃ : κ₃₁ = 0.8510 : 0.04498 : 0.8720

归一化（和=1.768）：

κ₁₂ : κ₂₃ : κ₃₁ ≈ 0.481 : 0.026 : 0.493

**候选h3（余弦组合）**：

cosθ₁ ≈ cos(1.2870) ≈ 0.2790
cosθ₂ ≈ cos(0.2680) ≈ 0.9640
cosθ₃ ≈ cos(0.2230) ≈ 0.9750

cos(θ₁+θ₂) = cos(1.5550) ≈ 0.0108
cos(θ₂+θ₃) = cos(0.4910) ≈ 0.8820
cos(θ₃+θ₁) = cos(1.5100) ≈ 0.0628

h₃(θ₁,θ₂) = 0.2790×0.9640 − 0.0108 = 0.2582
h₃(θ₂,θ₃) = 0.9640×0.9750 − 0.8820 = 0.0579
h₃(θ₃,θ₁) = 0.9750×0.2790 − 0.0628 = 0.2092

κ₁₂ : κ₂₃ : κ₃₁ = 0.2582 : 0.0579 : 0.2092

归一化（和=0.5253）：

κ₁₂ : κ₂₃ : κ₃₁ ≈ 0.492 : 0.110 : 0.398

#### 4.4 与候选1（S_iS_j）的比例对比

候选1（双线性耦合κ_ij = κ₀S_iS_j）的比例为：

S₁S₂ : S₂S₃ : S₃S₁ = 0.1091 : 0.01894 : 0.0908

归一化（和=0.2188）：

κ₁₂ : κ₂₃ : κ₃₁ ≈ 0.499 : 0.086 : 0.415

| 候选 | κ₁₂ | κ₂₃ | κ₃₁ | 特征 |
|------|-----|-----|-----|------|
| 候选1（S_iS_j） | 0.499 | 0.086 | 0.415 | 基准 |
| h1（正弦乘积） | 0.484 | 0.112 | 0.404 | 接近候选1 |
| h2（角度差正弦） | 0.481 | 0.026 | 0.493 | κ₂₃极小 |
| h3（余弦组合） | 0.492 | 0.110 | 0.398 | 接近候选1 |

**分析**：

- 候选h1和h3的比例分布与候选1（S_iS_j）非常接近，三者都预测κ₁₂ ≈ 0.50, κ₃₁ ≈ 0.40, κ₂₃ ≈ 0.10
- 候选h2预测κ₂₃极小（0.026），与候选1的0.086差异较大，可作为判别依据
- 候选h1和h3的相似性表明：在小角度近似下（θ₂, θ₃ << 1），正弦乘积和余弦组合趋于一致

#### 4.5 方案A的阶段性结论

1. **候选h1和h3与候选1（S_iS_j）自洽**，三者给出相似的κ_ij比例分布
2. **候选h2（角度差正弦）可被排除**，因其预测κ₂₃过小（0.026），与候选1的0.086差异显著
3. 候选h1和h3之间目前无法区分，需要中介层的反馈约束来判别

**方案A的输出**：κ₁₂ : κ₂₃ : κ₃₁ ≈ 0.50 : 0.10 : 0.40（候选h1或h3）。κ₀的精确值仍需中介层反馈才能最终确定。
