## 文章12第2节：T⁸变形极限下的代数验证

### 2.1 任务定位

第2节是“三管齐下”策略中的代数验证环节。目标是：

1. 在T⁸变形（接近平坦极限）的简化设定下，完整跑通从M₈映射公式到C_mid提取的推导流程
2. 验证张量缩并与微扰展开的代数自洽性——确保在投入CY4的复杂计算之前，底层逻辑无误
3. 确认当χ_g → 0时，$ε_geom$严格退化为0.2348κ₀（与文章11一致），当$χ_g$ ≠ 0时，代数框架能正确提取出C_mid

### 2.2 T⁸变形的参数化

纯平坦T⁸的黎曼曲率张量为零，$χ_g$ = 0，此时C_mid = 0。为了测试非零$χ_g$下的代数框架，引入一个微小形变参数δ来描述偏离平坦的程度。

T⁸变形的度量可写为：

$g_ab = δ_ab + h_ab$

其中h_ab是微小扰动（|h_ab| << 1），由形变参数δ控制。在δ → 0的极限下，回到纯平坦T⁸。

对于8维环面的变形，其Euler示性数在拓扑上仍为χ = 0（环面的Euler示性数恒为零），但曲率积分非零。在微小形变下，曲率张量$R_abcd ∝ δ²$ ，因此$χ_g ∝ δ²$ 。

$χ_g$的具体形式可写为：

$χ_g = χ_g⁽²⁾ · δ² + O(δ⁴)$

其中χ_g⁽²⁾是与形变模式相关的二阶系数矩阵。在代数验证中，我们不需要知道χ_g⁽²⁾的具体数值，只需确认它在代数框架中能被正确处理。

### 2.3 张量缩并流程验证

M₈映射公式的核心项为：

$vᵀM₁^(1/2) χ_g M₁^(1/2) v$ 

其中$v = (√S₁, √S₂, √S₃)$ 已知，$M₁^(1/2) = diag(√S₁, √S₂, √S₃)$ （在忽略κ_nd的一阶近似下）。

**代入$S_i$ 数值：**

M₁^(1/2) = diag(0.8507, 0.3883, 0.3543)

v = (0.8507, 0.3883, 0.3543)

注意：v与M₁^(1/2)的对角元完全相同（因为v_i = √S_i），因此：

$vᵀM₁^(1/2) = (S₁, S₂, S₃) = (0.7237, 0.1508, 0.1255)$

这是一个重要的简化——vᵀM₁^(1/2)恰好等于(S₁, S₂, S₃)，即M₁⁰的对角元组成的行向量。

因此：

$vᵀM₁^(1/2) χ_g M₁^(1/2) v = (S₁, S₂, S₃) · χ_g · (S₁, S₂, S₃)ᵀ= Σ_i Σ_j S_i S_j (χ_g)_ij$

这是一个双线性型，其中χ_g是8×8矩阵（在T⁸的切空间上），S_i需要嵌入到8维空间中。

### 2.4 维度嵌入与缩并

这里有一个关键的代数细节需要处理：v是3维矢量（根域3个时序通道），而χ_g是8×8矩阵（M₈的切空间）。两者的维度不同，缩并时需要将v嵌入到8维空间中。

嵌入规则：根域的3个时序通道对应M₈的3个特定方向（记为方向1,2,3），其余5个方向（方向4-8）对应M₈的其他自由度（空间维度的投影映射等）。在T⁸变形下，这5个方向可以取为平坦（无曲率），因此χ_g在这些方向上的分量为零。

因此，χ_g的非零分量仅限于前3×3的子块：

$χ_g = diag(χ_g⁽³⁾, 0₅)$

其中χ_g⁽³⁾是3×3矩阵，0₅是5×5零矩阵。

代入缩并式：
$$
vᵀM₁^(1/2) χ_g M₁^(1/2) v = Σ_{i=1}³ Σ_{j=1}³ S_i S_j (χ_g⁽³⁾)_ij
$$
### 2.5 C_mid的提取

根据文章11的ε_geom表达式：

$ε_geom = 0.2348κ₀ + C_mid κ₀² + ...$

其中$C_mid$来自χ_g的贡献：

C_mid κ₀² = (vᵀM₁^(1/2) χ_g M₁^(1/2) v) / (vᵀM₁⁰v)

代入vᵀM₁⁰v = 0.5623：

C_mid κ₀² = [Σ_i Σ_j S_i S_j (χ_g⁽³⁾)_ij] / 0.5623

在T⁸变形下，χ_g⁽³⁾ ∝ δ²，因此：

C_mid = [Σ_i Σ_j S_i S_j (χ_g⁽²⁾)_ij] / 0.5623 · δ²/κ₀² + O(δ⁴)

当δ → 0时，$C_mid → 0，ε_geom → 0.2348κ₀$ ，与文章11一致。✅

当δ取有限值时，代数框架给出有限的C_mid值，且不出现奇点或维度错误。✅

### 2.6 验证结论

T⁸变形下的代数验证确认：

1. **张量缩并无奇点**：$vᵀM₁^(1/2)χ_gM₁^(1/2)v$ 的维度嵌入规则自洽，3维→8维的嵌入不引入代数错误
2. **极限退化正确**：当χ_g → 0（δ → 0）时，C_mid → 0，ε_geom退化为0.2348κ₀，与文章11一致
3. **代数框架可扩展**：当χ_g取非零形式时，C_mid的提取公式闭合，无发散或维度不匹配问题

**代数验证通过。** 可以进入第3节——CY4基准下的C_mid精确计算。
