## 文章11：κ₀量级估算与自洽性检验（P0-2）

### 第1节：任务定位与前置条件

#### 1.1 P0-2的任务

P0-2是P0（κ_nd内部几何定标）的收尾阶段。基于P0-1（文章10）的输出——κ₁₂:κ₂₃:κ₃₁ ≈ 0.50:0.10:0.40的比例关系和κ₀ < 2.12的上限——本文的任务是：

1. 利用M₈中介层的自洽性条件，建立ε_geom对κ₀的依赖关系
2. 提取主项，在不对M₈几何形态做具体假设的前提下，估算κ₀的量级
3. 验证κ₀ ~ 10⁻²的预期是否自洽
4. 根据量级估算结果，决定后续路径：推进精确计算或回退

#### 1.2 前置条件清单

在开始量级估算之前，将已知量与未知量明确分离，确保推导过程的透明度。

#### 1.3 方法论：量级估算优先于精确计算

M₈的几何形态目前有多个候选（CY4、Spin(7)、T⁸变形等），它们在拓扑不变量（如Euler示性数χ_g、体积模V₈）上有显著差异。如果在形态未定的情况下直接代入某一具体形态的χ_g进行精确计算，得到的κ₀值将无法区分是物理结果还是形态选择的假象。

量级估算的策略是：**将形态依赖的拓扑因子归入O(1)系数，先看κ₀的主项量级是否与微扰假设自洽。**

具体而言，自洽性条件ε_geom对κ₀的依赖关系可写为：

ε_geom = C · κ₀² · [1 + O(κ₀)]

其中系数C由两部分组成：

C = C_root × C_mid

- C_root：来自根域层的贡献（S_i、θ_i、比例关系），可精确计算
- C_mid：来自中介层的贡献（χ_g、V₈的某种组合），形态依赖，本次估算中取O(1)

这样，不确定性被严格限制在形态依赖的因子上，根域层的贡献是精确的。

#### 1.4 主项阶数的预判

根据文章10第3节的微扰分析，一阶微扰修正为0（因为M₁⁽¹⁾的对角元为0），因此ε_geom对κ₀的最低阶贡献是κ₀²阶：

ε_geom(κ₀) = c₂κ₀² + c₃κ₀³ + ...

其中c₂由根域层参数（S_i、比例关系）和中层几何因子共同决定。

这意味着：
- 如果ε_geom ~ 10⁻⁴（典型微扰量级），则κ₀ ~ 10⁻²
- 如果ε_geom ~ 10⁻²，则κ₀ ~ 10⁻¹

这两种情况都与已有文档中κ_nd ~ 10⁻³~10⁻²的预期大致自洽。如果估算结果偏离这个范围超过一个量级，则需要重新审视候选函数形式或微扰假设本身。
