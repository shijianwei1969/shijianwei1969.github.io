## 附录A：为什么 G 和 c 在广阔能量区间内刚性——两级解耦与相对论弦自稳定机制

### 摘要

超定域根域辐照的基底能量，在信息熵 206 bits 高点到 $10^{-15}$ J/m² 低点的广阔区间内，$G$ 与 $c$ 始终保持刚性。本文给出该客观事实的系统性解释：$G$ 与 $c$ 属于单根根域联络单元的固有拓扑参数（层次A），$E_V$ 属于联络单元的组装密度（层次B）。两级解耦使 $G$、$c$ 在能量密度跨越 40 个数量级以上时仍严格刚性。机制的核心动力学根源是相对论弦自稳定：$T = \mu c^2$ 导致波速 $v = \sqrt{T/\mu} = c$，$\mu$ 在波速中消去，波速天然免疫于介质密度变化。本文同时界定两个失效边界（超级中心、深空边界），与主文档严格一致。

### A.3 动力学根源：相对论弦自稳定

**普通介质做不到：** 普通介质的波速 $v = \sqrt{\text{弹性模量}/\rho}$。密度一变，波速必变。水的声速变 5 倍。量子海若照此规律，40 个数量级的能量变化早已使 $c$ 面目全非。

**相对论弦的天然免疫：** Nambu-Goto 弦有一条**定义性**关系：

$T = \mu c^2$

其中 $T$ 为弦张力，$\mu$ 为线密度，$c$ 为根域光速。由此弦上的波速：

$v = \sqrt{\frac{T}{\mu}} = \sqrt{\frac{\mu c^2}{\mu}} = c$

**$\mu$ 消掉了。** 无论线密度如何变化，张力与密度的比值自动恒定，波速严格等于 $c$。

> **严谨性说明：** $T = \mu c^2$ 是 Nambu-Goto 弦的**定义性设定**（作用量 $S = -T \int d^2\sigma$ 中 $T = \mu c^2$），**并非从第一性原理推导的定理**。本文将其作为 11T-Matrix 的体系内假设引入；从 $M_3$（时序饱和度）与 $M_4$（自旋拓扑）严格推出此关系仍是待完成项（见 A.7）。

1. **层次B变化**：联络间距拉大，$n_{\rm link}$ 急剧下降，单个联络的能量承载减少；
2. **层次A不变**：单根弦的 $\lambda_{\rm topo}$、$\tau_0$ 仍由拓扑锁定，$T = \mu c^2$ 关系在每根弦上依然成立；
3. **结果**：每根弦上的波速仍然是 $c$。整片量子海的宏观响应（$G$、$c$）不变。

### A.4 信息熵 206 bits 的定位
