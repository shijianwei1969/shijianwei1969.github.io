# P1阶段（中介层$\chi_g$几何相对定标）总结报告
## 一、阶段定位与目标
P1是连接根域层（P0已完成$\kappa_{nd}$全定标）与表象层（P2待对接可观测量）的核心衔接阶段，核心目标为：
1. 确立中介层的几何载体框架
2. 完成引力极化率$\chi_g$的微观定义与相对数值定标
3. 建立根域通道到中介层的投影映射规则
4. 验证根域-中介层全链路自洽性与微扰收敛性

本阶段所有结论均建立在**单模CY4（$\mathbb{P}^5$六次超曲面）建构性假说**之上，不声称内生推导的必然性，仅验证假说框架下的自洽性与可检验性。

## 二、核心成果汇总
### 1. 中介层几何载体：建构性假说框架建立
- **假说内容**：中介层几何载体为单模Calabi-Yau 4-fold（$\mathbb{P}^5$六次超曲面，$h^{1,1}=1$），单模属性为附加简化假说，可被多模模型替代。
- **可证伪体系**：
  - 弱证伪判据：$t\in[50,100]$、$\zeta\in[0.3,0.7]$范围内，无法同时拟合两个独立可观测量
  - 强证伪判据：三个独立可观测量超定检验无合理解
- **可替代标准**：满足「假设更少、预测精度更高、参数空间更紧凑」中任意两条，即可替代当前假说
- **边界拆分**：明确$X_8$示性类、Pontryagin-Chern类换算为通用数学工具，不绑定CY4假说

### 2. $\chi_g$微观定义与形式定标
- **曲率响应溯源**：引力极化率的二阶响应形式来自Atiyah-Singer指标定理标准$X_8$示性类，系数比$A:B=3:(-1)$，为纯代数拓扑结论，无外源物理依赖。
- **全局数值（相对定标）**：$\mathcal{N}=1$约定下，全局拓扑积分$\int_{M_8}(3c_2^2 - c_4)=1440$，结合单模体积公式$V_8=t^4/4$，得：
  $$\chi_g = \frac{5760}{t^4}$$
- **正定性验证**：全局积分值为正，满足极化率物理要求，属于假说成立的必要条件。

### 3. 局域化投影规则建立
- **加权调和基底构造**：根域通道权重通过加权调和形式传递：$\omega_i = \sqrt{S_i}\hat{u}_i$，其中$\hat{u}_i$为$\text{Prim}^{2,2}$子空间中$S_3$轮换对称的正交单位基底。
- **投影张量形式**：
  - 对角项：$(\chi_g^{(3)})_{ii} = \lambda_{\text{eff}} S_i$（通道权重线性传递）
  - 交叉项：$(\chi_g^{(3)})_{ij} = \mu_{\text{eff}} \sqrt{S_i S_j}$（交叉耦合为几何重叠效应）
- **定位说明**：加权构造为功能性衔接设计，非根域公理必然推导，数学上符合加权Hodge理论标准操作，全链路自洽性验证通过。

### 4. 有效极化率参数定标
- **基准数值（约定下锁定）**：取文献参考值$\zeta=0.5$（通道总覆盖率）、$r_{\text{cross}}=1/3$（交叉重叠比），得：
  $$\lambda_{\text{eff}}=\frac{2880}{t^4}, \quad \mu_{\text{eff}}=-\frac{1740}{t^4}$$
- **参数定位**：$\zeta$、$r_{\text{cross}}$当前为弦论CY4紧化文献采纳值，非本体系内生结论，存在$0.3\sim0.7$的浮动范围，留待P2-2实验反锁精确值。
- **比值自洽**：$\mu_{\text{eff}}/\lambda_{\text{eff}}=-29/48$，与$A:B$比值、交叉分配规则完全闭合。

### 5. 大体积压制机制验证
- **压制本质**：投影空间体积对拓扑曲率积分的稀释效应（非弦论大体积紧化），$\chi_g \propto 1/t^4$，无外源展开参数依赖。
- **收敛性验证**：基准$t=75$时，二阶项/一阶项比值为$4.88\%$，微扰展开高度收敛；$t\approx42$为收敛阈值，$t<30$发散。
- **回传影响验证**：中介层二阶效应对根域$\kappa_0$的修正量级为$10^{-9}$，相对占比不到百万分之一，不影响P0阶段定标结果。

### 6. 根域-中介层全链路自洽性验证
- $\varepsilon_{\text{geom}}$展开式闭合：一阶项$0.2348\kappa_0$（根域贡献）、二阶项$C_{\text{mid}}\kappa_0^2$（中介层贡献）的比例符合微扰预期，无数量级冲突。
- 通道权重传递自洽：$S_i$归一化特性与投影积分规则匹配，无循环逻辑问题。
