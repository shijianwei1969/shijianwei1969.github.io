# 文章 1：量纲与自洽性检查

## 1. 问题定义

我们需要确认：α 是无量纲的，θ_i = Ω_i / N_i 在量纲上是否闭合，以及 TRT 的 Ω_i（π, π², 4π³）在 v7.0 框架里对应什么物理量。

## 2. M₄ 的量纲分析

M₄ 的定义：

$$
M_4 = i\omega_0 \cdot \mathcal{N}_4
$$

其中：

- ω₀ = 2πc / λ_c，λ_c = l_r,0 / 3
- ω₀ 的量纲：[ω₀] = [T⁻¹]（频率）
- 𝒩₄ 是无量纲的整数矩阵（N_i 是圈数，δ_ij 是复数耦合系数，均无量纲）

所以 M₄ 的量纲是 [T⁻¹]。

但 α 是无量纲的。这意味着 α 不是直接从 M₄ 的某个元素读出来的，而是从 M₄ 的某个**比值**或**组合**里出来的。

在 M₄ 的原始设定中，α 来自 M₄ 的“chiral 读数”——具体来说，是 M₄ 的虚部与某个参考量（如 M₁ 的投影体积 4π，或 ω₀ 的倒数周期）的比值。这个比值消掉了 ω₀ 带来的 [T⁻¹] 量纲，使 α 成为纯数。

**结论**：α 的无量纲性不是问题，它来自 M₄ 读数与参考量的比值，量纲自然消掉。这条路径在 v7.0 框架中已隐含，无需额外修正。

## 3. θ_i 的量纲分析

θ_i 的定义：

$$
\theta_i = \frac{\Omega_i}{N_i}
$$

其中：

- N_i 是圈数，无量纲
- Ω_i 是 TRT 的“几何当量”：Ω₃ = π，Ω₂ = π²，Ω₁ = 4π³

π 是纯数（圆周率），所以 Ω_i 也是纯数，无量纲。

因此 θ_i = Ω_i / N_i 也是纯数，无量纲。

**结论**：θ_i 无量纲，与 α 无量纲一致。量纲闭合，没有问题。

## 4. Ω_i 的物理对应

TRT 的 Ω_i 虽然是纯数，但它们有几何来源：

- Ω₃ = π：对应单位半径圆的面积（π·1²）
- Ω₂ = π²：对应单位半径圆柱螺旋的扫掠面积（π·1 × π·1 = π²）
- Ω₁ = 4π³：对应单位半径球面的面积（4π·1²）乘以 π 的某种升维因子（4π³ = 4π·π²）

在 v7.0 框架中，这些 Ω_i 对应的是 **M₁ 投影算子在每个通道上的“投影几何当量”**——即根域缠绕在表象时空中展开的“有效面积/体积”。它们是无量纲的，因为根域拓扑的“尺寸”由 l_r,0 锚定，而 l_r,0 的量纲在 ω₀ 和 λ_c 中已经被吸收了。

**结论**：Ω_i 是无量纲的几何当量，对应 M₁ 投影的通道产出。量纲自洽。

## 5. 整体自洽性检查

| 量 | 表达式 | 量纲 | 说明 |
|:---|:---|:---:|:---|
| N_i | 13, 34, 89 | 无 | 圈数，纯整数 |
| Ω_i | π, π², 4π³ | 无 | 几何当量，纯数 |
| θ_i | Ω_i / N_i | 无 | 每圈当量，纯数 |

| M₄ | iω₀·𝒩₄ | [T⁻¹] | 矩阵，α 来自其比值读数 |
| ω₀ | 2πc/λ_c | [T⁻¹] | 频率，在 α 比值中被消掉 |

**结论**：量纲完全闭合，无隐藏矛盾。
