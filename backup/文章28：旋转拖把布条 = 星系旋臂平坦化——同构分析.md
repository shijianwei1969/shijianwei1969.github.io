# 旋转拖把布条 = 星系旋臂平坦化——同构分析

**作者：史建威**。本文为P4阶段独立文章（Article-28），基于本体论四大公理与11时序矩阵框架，以日常器物同构揭示星系形态学的底层机制。

## 摘要

星系旋转曲线平坦化（外围速度不降）和旋臂形态（对数螺旋）是盘状星系的两个核心观测特征。标准宇宙学用暗物质晕解释平坦化、用密度波理论解释旋臂——两套独立机制，互不隶属。

本文提出一个日常同构：**竖直提起一把湿拖把，旋转拖把柄，布条被甩开的形态和动力学，与盘状星系完全同构。** 在这个同构中：

- **拖把柄** = 星系核球/中心区（紧态返祖，λ偏高）；
- **布条** = 星系盘上的“物质链”——从内到外，大天体（紧态）层层俘获小天体/星云（松态），形成“大鱼吃小鱼、大鱼带小鱼”的层级柔性链；
- **旋转柄** = 星系整体角动量驱动；
- **布条甩平（平坦化）** = 松态（星云）根侧当量大 → 外段被超额带动 → 速度不掉；
- **布条扭成螺旋（旋臂）** = 布条内部根侧当量梯度（内紧外松）+ 差转剪切 → 自然扭出对数螺旋。

**核心结论**：平坦化和旋臂是同一“甩动”动作的两个读数——不需要暗物质粒子，不需要密度波图案，只需承认“松态物质根侧当量大”这一本体论公理推衍。

## 1 引言：两个谜题，一个同构

### 1.1 盘状星系的两个核心观测特征

1. **旋转曲线平坦化**：星系外围（光学盘以外）的恒星/气体绕转速度不随半径增加而下降（开普勒定律预期 $v \propto 1/\sqrt{r}$），而是保持近乎恒定。ΛCDM的解释：引入暗物质晕，追加额外质量剖面。
2. **旋臂形态**：大多数盘状星系呈现对数螺旋形的明亮臂结构。ΛCDM的主流解释：密度波理论（Lin & Shu 1964）——图案波以固定角速度旋转，物质穿臂而过，臂是波峰而非物质聚集。

这两个解释**彼此独立**——暗物质晕负责平坦化，密度波负责旋臂，两者在标准模型中没有任何必然联系。

### 1.2 一个日常同构

想象一把湿拖把：竖直提起，握住柄的上端旋转。布条会怎样？

- 布条被甩开，**整体形成一个旋转的锥面/盘面**；
- 每根布条的**外端速度不比内端慢多少**（因为布条是软的，外端被内端拖着走）——**平坦化**；
- 每根布条不是直线，而是**被扭成弧形/螺旋**——**旋臂**；
- 布条越湿（越软、越松散），甩开的效果越明显。

**这就是盘状星系的完美同构。**

### 2.2 关键：布条为什么是“软”的？

拖把布条软，是因为纤维之间有间隙、有水、可以相对滑动。星系“布条”软，是因为：

> **同一物质链上，从内到外，松态（星云）占比递增，紧态（天体）占比递减。**

而松态物质有一个关键性质（P4-S01已建立）：**松态基本粒子在超定域时空的概率云铺开尺度大 → 根侧当量大 → 同样冠侧质量M，等效引力贡献更大。**

这意味着：

- **布条根部**（近柄，大天体为主，紧态）：根侧当量中等偏小 → 惯性显，对引力拽的响应相对“钝”；
- **布条梢部**（远端，星云为主，松态）：根侧当量大 → 对引力拽的响应“灵敏”，容易被内段超额带动。

**整根布条不是刚体，而是“梢比根更容易被带”的柔性链。** 这正是拖把布条软的微观本体论根源。

## 3 平坦化：布条为什么被甩平

### 3.1 标准模型的困境

按开普勒定律，星系外围物质绕转速度应满足 $v(r) \propto 1/\sqrt{r}$。但观测显示 $v(r)$ 在外围近乎恒定。ΛCDM 的解法：在已有重子物质之外，追加一个暗物质晕的质量剖面 $M_{\text{DM}}(r)$，使得总质量 $M_{\text{tot}}(r) = M_{\text{baryon}}(r) + M_{\text{DM}}(r)$ 给出的 $v(r)$ 平坦。

**问题**：暗物质粒子至今未被探测到，且需要精细调节晕剖面来匹配不同星系的旋转曲线。

### 3.2 拖把同构的解释

拖把布条被甩平时，**外端速度为什么不掉？**

直观答案：因为布条是软的，外端被内端“拖着走”。内端（近柄）转得快，通过布条的柔性连接把力矩传到外端，外端虽然离轴远，但**没有被松开**——它被迫跟随内端的节奏。

星系版的对应：

> **盘的外围物质（松态星云）根侧当量大 → 等效引力贡献大 → 它们被内圈物质（紧态天体）的引力拽着走的“力度”比纯牛顿预期更强 → 外段速度不掉。**

这不是“加了额外质量”，而是**已有质量的等效引力贡献被根侧加权放大了**。加权因子来自超定域铺开张力（P4-S01）：松态物质在根域铺得开，根侧当量高于同冠侧M的紧态物质。

### 3.3 数学形式（定性）

平坦化条件：

$$
v_{\text{flat}}^2 \approx \frac{G}{r} \int_0^r M_{\text{baryon}}(r') \cdot w[\lambda_{\text{local}}(r'), \text{spread}] \, dr'
$$

其中 $w[\lambda, \text{spread}] > 1$ 对松态（$\lambda \ll \lambda_c$），$w \approx 1$ 对紧态（$\lambda \gg \lambda_c$）。精确函数形式待P5阶段引力极化理论完成后确定，但定性趋势已足够解释平坦化。

## 4 旋臂：布条为什么被扭成螺旋

### 4.1 标准模型的困境

密度波理论（Lin-Shu）认为旋臂是自引力不稳定性激发的图案波，图案以固定角速度 $\Omega_p$ 旋转，物质以 $\Omega(r)$ 差转穿臂而过。这个理论成功解释了一些观测，但也有困难：

- 需要精细调节激发/阻尼机制来维持图案；
- 多臂星系的各臂可能对应不同 $\Omega_p$，与单一图案波冲突；
- 某些星系的旋臂看起来更像物质臂（material arms），而非波臂。

### 4.2 拖把同构的解释

拖把布条为什么被扭成螺旋？

直观答案：因为**布条根部（近柄）转得快，梢部（远端）转得慢（差转），但布条又是软的（梢被根拖着走）**——根部已经转过一个角度，梢部还没来得及跟上，于是布条被“拧”成了弧形。持续旋转下，这个弧形被拉伸成对数螺旋。

星系版的对应完全平行：

> **盘的内圈（近核球）Ω大，外圈Ω小（差转）。但“布条”（物质链）是软的——外圈松态物质根侧当量大，被内圈紧态物质超额带动。内圈已转过一个角度，外圈滞后，物质链被“拧”成螺旋。**

**关键**：这个螺旋不是先存的波，而是**持续差转 + 柔性链（根梢响应不均）的自然产物**。不需要密度波作为独立实体。

### 4.3 为什么是对数螺旋

差转盘中，物质链被拧的自然本征模就是对数螺旋：

$$
r = r_0 e^{\theta \tan i}
$$

其中 $i$ 是螺距角（pitch angle）。在拖把同构中，pitch角由两个因素决定：

1. **差转剪切率** $d\Omega/dr$（由盘的质量分布决定）；
2. **布条的“柔性”**（由松态占比 + 根侧当量梯度决定）。

松态占比高（布条更软）→ pitch角大（臂松，Sc星系）；松态占比低（布条更硬）→ pitch角小（臂紧，Sa星系）。这与观测序列定性一致。

### 4.4 “大鱼吃小鱼”的层级嵌套

一根布条不是“一个大天体 + 一团云”的简单二元结构，而是：

```
柄（核球/SMBH）
 └─ 大天体A + 大星云A（A在近柄轨道，λ_A中偏高）
      ├─ A俘了中天体B + 中星云B（B在A的引力阱里，λ_B中）
      │    └─ B俘了小鱼C + 小云C（λ_C偏低，更松）
      │         └─ ……
      └─ A还直接俘了游离云D（更松，λ_D极低）
```

每一级都是“上一级紧态做受体，下一级松态做供体”——递归的鱼吃鱼。整根布条的软性来自每一级的“松紧根侧差”累积。这解释了为什么旋臂不是单一线条，而是有粗细、有分支、有内部结构的复杂形态。

## 6 同构的启示：日常器物为何能与星系同构

### 6.1 这不是巧合

拖把布条和星系旋臂的同构，不是肤浅的“看起来像”，而是**深层动力学同构**：

| 要素 | 拖把布条 | 星系物质链 |
|:-----|:---------|:-----------|
| 驱动源 | 柄旋转（中心驱动） | 整体角动量（种子冷却遗产） |
| 柔性来源 | 纤维间隙+水（物理柔性） | 松态根侧当量大（本体论柔性） |
| 差转 | 根部Ω大，梢部Ω小（几何） | 内圈Ω大，外圈Ω小（开普勒/平坦化） |
| 形态 | 对数螺旋 | 对数螺旋 |

**两者共享同一套“差转+柔性链”的动力学方程**——只是拖把的柔性来自材料，星系的柔性来自根侧当量梯度。数学同构，本体不同。

### 6.2 公理化框架的威力

标准模型在平坦化（暗物质）和旋臂（密度波）上用两套独立机制，彼此无推导关系。本体论框架从四大公理出发，推衍出“松态根侧当量大”这一性质，然后**用一个同构同时解释了平坦化和旋臂**——不需要额外假设，不需要新粒子。

这正是公理层面普遍解释方式的体现：**越基础的公理，能解释的现象越多。**

## 7 诚实披露与遗留问题

1. **根侧当量加权函数 $w[\lambda, \text{spread}]$ 的精确形式**：当前仅定性，待P5阶段引力极化理论完成后确定；
2. **“布条”之间的相互作用**：拖把布条之间也有摩擦和纠缠，星系中不同物质链之间也有引力/潮汐相互作用——当前未建模；
3. **多臂星系的精确形成**：当前用“主布条+次级布条”定性解释，定量模拟需N-body+松态加权；
4. **棒旋星系的棒**：拖把同构中柄是直的，但棒旋星系有棒——棒可能是“柄的延伸”或“内圈布条被过度拧紧后的形态转变”，待后续研究；
5. **椭圆星系**：拖把同构适用于盘状星系（旋涡/棒旋），椭圆星系可能需要另一套同构（如“揉成一团的拖把布”）。

**平坦化和旋臂不是两个独立现象，而是同一“甩动”的两个读数。** 不需要暗物质粒子，不需要密度波图案——只需承认“松态物质根侧当量大”这一本体论公理推衍。
